Two of the most consistent infrastructure signals in threat hunting are the top-level domain (TLD) of a destination and the autonomous system number (ASN) that hosts it. Attackers deliberately choose cheap, permissive, or loosely-governed TLDs and hosting providers because they offer fast registration, minimal identity verification, and slow takedown processes.

## Suspicious TLDs

A TLD is the rightmost label in a domain name (`.icu`, `.tk`, `.ml`, etc.). Certain TLDs are disproportionately associated with phishing, malware distribution, and C2 infrastructure because:

- Registration is free or near-free, lowering the cost of disposable domains
- Registry operators have weak or no abuse reporting procedures
- They are rarely used for legitimate enterprise traffic, making them high-signal when they appear in network logs

### CSV structure — suspicious_tlds_list.csv

| Column | Description |
|---|---|
| `url_domain` | TLD pattern (e.g. `*.icu`) |
| `metadata_tld` | TLD label without leading dot |
| `metadata_category` | Abuse type: `Malware`, `Phishing`, `C2`, `Suspicious` |
| `metadata_popularity` | Legitimate usage popularity: `Low`, `Medium`, `High` |
| `metadata_severity` | Risk level: `Critical`, `High`, `Medium`, `Low` |
| `metadata_comment` | Context and observed abuse patterns |
| `metadata_link` | External reference |

**Example rows:**

```csv
url_domain,metadata_tld,metadata_category,metadata_popularity,metadata_severity,metadata_comment,metadata_link
```

### Example Splunk query using TLD lookup

Upload `suspicious_tlds_list.csv` as a Splunk lookup table, then:

```spl
index=network sourcetype=proxy OR sourcetype=dns
| rex field=dest_host "\.(?<tld>[^.]+)$"
| eval url_domain="*.".tld
| lookup suspicious_tlds_list.csv url_domain OUTPUT metadata_category metadata_severity metadata_comment
| where isnotnull(metadata_severity)
| eval risk=case(
    metadata_severity="Critical", 4,
    metadata_severity="High",     3,
    metadata_severity="Medium",   2,
    true(),                       1
  )
| table _time src_ip dest_host tld metadata_category metadata_severity metadata_comment
| sort -risk
```

Focus on critical-severity TLDs for alerting:

```spl
index=network sourcetype=proxy
| rex field=dest_host "\.(?<tld>[^.]+)$"
| eval url_domain="*.".tld
| lookup suspicious_tlds_list.csv url_domain OUTPUT metadata_severity metadata_category
| where metadata_severity="Critical"
| stats dc(dest_host) as unique_domains, count as requests by src_ip metadata_category
| where requests > 5
```

## Suspicious ASNs

An ASN (Autonomous System Number) identifies a network operator on the internet. Certain ASNs are persistently associated with bulletproof hosting, spam, phishing infrastructure, and malware distribution because their operators have weak or non-existent abuse handling policies.

| Column | Description |
