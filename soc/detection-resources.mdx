## Living-Off-the-Land (LOL) resources

These resources catalog legitimate binaries, drivers, and services that adversaries abuse. The detection lists in this collection include synchronized copies of several LOL datasets (e.g., `loldrivers_only_hashes_list.csv`).

<CardGroup cols={2}>
  <Card title="LOLBAS" icon="terminal" href="https://github.com/mthcht/LOLBAS">
    Living Off the Land Binaries, Scripts, and Libraries — Windows binaries with documented abuse cases.
  </Card>
  <Card title="GTFOBins" icon="terminal" href="https://github.com/mthcht/GTFOBins.github.io">
    Unix binaries that can be exploited to bypass security controls or escalate privileges.
  </Card>
  <Card title="LOLDrivers" icon="microchip" href="https://www.loldrivers.io/">
    Vulnerable and malicious Windows drivers used in BYOVD (Bring Your Own Vulnerable Driver) attacks. Hash list synced into `loldrivers_only_hashes_list.csv`.
  </Card>
  <Card title="LOLRMM" icon="monitor" href="https://github.com/magicsword-io/LOLRMM">
    Remote monitoring and management (RMM) tools abused by threat actors. Synced into the RMM detection lists.
  </Card>
  <Card title="LOLC2" icon="network" href="https://github.com/lolc2/lolc2.github.io">
    Legitimate services and protocols used to host or tunnel C2 communications. Referenced in `lolc2_abused_domains.csv`.
  </Card>
  <Card title="LOLESXI" icon="server" href="https://github.com/LOLESXi-Project/LOLESXi">
    Techniques and binaries native to VMware ESXi hypervisors that ransomware groups exploit.
  </Card>
  <Card title="WTFBIN" icon="code" href="https://wtfbins.wtf/">
    A catalog of unusual, abusable, or risky binaries and their documented behaviors.
  </Card>
  <Card title="LOTS Project" icon="cloud" href="https://lots-project.com/">
    Living Off Trusted Sites — legitimate cloud services (GitHub, OneDrive, Dropbox) abused for C2, exfiltration, or hosting payloads.
  </Card>
  <Card title="LOLOLFarm" icon="leaf" href="https://lolol.farm/">
    An aggregator that indexes content from LOLBAS, GTFOBins, LOLESXI, LOLRMM, and other LOL projects in one searchable interface.
  </Card>
</CardGroup>

<Note>
  The lists in `Lists/Drivers/` are updated automatically via CI. Pull the latest version before building detections on driver hashes.
</Note>

## Detection rule repositories

### Sigma

Sigma is the vendor-neutral detection rule format. Rules can be converted to Splunk SPL, Elastic EQL, KQL, and QRadar AQL using [sigma-cli](https://github.com/SigmaHQ/sigma-cli) or [Uncoder.io](https://uncoder.io/).

<CardGroup cols={2}>
  <Card title="SigmaHQ (official rules)" icon="file-code" href="https://github.com/mthcht/sigma/tree/master/rules">
    The primary Sigma rule repository maintained by the Sigma project.
  </Card>
  <Card title="DFIR-Report Sigma Rules" icon="file-code" href="https://github.com/The-DFIR-Report/Sigma-Rules">
    Rules authored from real incident investigations published by The DFIR Report.
  </Card>
  <Card title="JoeSecurity Sigma Rules" icon="file-code" href="https://github.com/joesecurity/sigma-rules/tree/master/rules">
    Rules derived from malware analysis runs in the Joe Sandbox environment.
  </Card>
  <Card title="mdecrevoisier Sigma Rules" icon="file-code" href="https://github.com/mdecrevoisier/SIGMA-detection-rules">
    A large community collection covering Windows event logs, network, and cloud sources.
  </Card>
  <Card title="P4T12ICK Sigma Rules" icon="file-code" href="https://github.com/P4T12ICK/Sigma-Rule-Repository">
    Community rules focused on endpoint and Active Directory detections.
  </Card>
  <Card title="tsale Sigma Rules" icon="file-code" href="https://github.com/tsale/Sigma_rules">
    Rules published by the author of the EDR Telemetry project, focusing on behavioral detections.
  </Card>
</CardGroup>

## KQL hunting queries
