## How to use these lists

<Steps>
  <Step title="Choose your detection category">
    Browse the Detection Lists tab to find the CSV files relevant to your threat hunting or detection use case — network indicators, host artifacts, malware signatures, or identity data.
  </Step>
  <Step title="Download the CSV directly from GitHub">
    Each list is a CSV file hosted on GitHub. Download it directly or reference the raw URL in your SIEM query or detection rule pipeline.
  </Step>
  <Step title="Integrate into your SIEM or EDR">
    Use the list as a lookup table in Splunk, an enrichment source in Elastic, or a reference dataset in any SIEM that supports CSV lookups. See the [quickstart guide](/quickstart) for platform-specific examples.
  </Step>
  <Step title="Keep lists up to date">
    Many lists are updated automatically (TOR nodes, VPN IPs, ASNs, TLDs, hijacklibs, LOLDrivers). Set up a scheduled pull or webhook to keep your lookups current.
  </Step>
</Steps>
